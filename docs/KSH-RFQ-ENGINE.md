# KSH — Smart Predictive RFQ Engine (2026)

## 1. Smart Spec Sheets & 3D/CAD Ingestion
- Ship owner cukup **unggah blueprint / file CAD/3D / dokumen teknis** — tanpa form rumit.
- **AI** mengekstraksi spesifikasi: **LOA, Breadth, Draft, GT**, tipe kapal.
- AI memetakan **repair list** / kebutuhan pembangunan baru secara instan.
- Output: spec sheet terstruktur, siap dilelang.

## 2. AI-Driven Matchmaking & Capacity Matrix
- Mencocokkan kebutuhan proyek dengan kapasitas mitra: ukuran dock, crane, **slot kosong**, spesialisasi.
- Proyek besar yang **tidak muat** di galangan fisik Balikpapan → dialokasi ke mitra ber-slot kosong.
- **Kalimas tetap Main Project Operator** (operator fee tetap mengalir).

## 3. Real-Time Dynamic Bidding Dashboard
- Ruang lelang transparan: **harga, estimasi durasi, garansi**.
- Visual: proyeksi biaya + **timeline Gantt otomatis** berbasis AI.
- Ranking penawaran objektif (harga, durasi, reputasi, kapabilitas).

## 4. Milestone-Linked Escrow & Blockchain Tracking
- Kontrak → dana terkunci di **escrow**.
- Progres fisik **terverifikasi (geo-tagged)** memicu pelepasan termin otomatis.
- **Ledger transparan** (immutable log / opsional blockchain) untuk audit & kepercayaan.

## KPI Engine
- Unggah blueprint → hasil matchmaking: **< 24 jam**.
- Rasio proyek ter-alokasi ke mitra: **> 70%** pada tahun pertama.
- Waktu pencairan termin setelah verifikasi: **< 48 jam**.
